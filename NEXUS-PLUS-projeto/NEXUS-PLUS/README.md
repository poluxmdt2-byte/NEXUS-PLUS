# NEXUS+

Projeto Android inicial do NEXUS+, com catálogo de WandaVision e reprodução de vídeos locais escolhidos pelo usuário.

## Gerar o APK
O workflow do GitHub Actions compila o app em cada push para `main` ou quando executado manualmente em Actions. O APK de depuração aparece como artefato `NEXUS-PLUS-APK`.

## Observação sobre vídeos
Os episódios não estão incluídos no projeto. No aplicativo, escolha arquivos de vídeo que você tenha direito de usar e que estejam salvos no seu aparelho.
